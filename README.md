# Public post archive

Self-contained static website. Upload the **contents** of this folder (not the enclosing folder) to a GitHub repository root and enable GitHub Pages from the `main` branch root. The archive contains HTML/CSS/JavaScript, CSV/JSON, and locally hosted screenshots.

## Record conventions

- Text is reproduced from the author's visible portion of the screenshots. Posts quoted underneath are visible only in their screenshot context.
- All original spelling and capitalization are retained in transcripts.
- Dates with an identifiable post ID are calculated from its UTC timestamp; otherwise they are dates shown in screenshots, without inferred times.
- Two screenshot-only entries lack an original post URL and are clearly marked on the website. Do not invent URLs for them.
- 'Selected statements' prioritizes direct group-directed or personal derogation, age-related remarks and social or intellectual status insults. It is not a legal finding. Other statements are retained under 'Additional context'.
- The screenshot of the 2024-12-26 DEI discussion shows the earlier message in the thread, while the text field corresponds to the post linked from the continuation.
- Public snapshots and mirrors are optional links, not replacements for the local screenshots.
- Keep a local backup. Public mirrors and GitHub Pages should not be treated as guaranteed permanent archival storage.

## Privacy

All PNGs were decoded to pixel data and newly encoded as RGB PNGs. No embedded EXIF, XMP, ICC or other auxiliary metadata is retained. Site assets use local relative URLs; no external scripts, fonts or analytics. GitHub independently publishes account and commit metadata, which this package cannot control.
